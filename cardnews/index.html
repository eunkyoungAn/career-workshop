수업 개요

학습 목표

  1. 카드뉴스 6장 구조(표지·문제·정보·선택 기준·CTA)에 맞춰 타깃과 주제를 정할 수 있다.
  2. 운영 시트와 Gemini 자동 생성 메뉴로 6장 원고를 만들고, 사실과 표현을 직접 검토할 수 있다.
  3. ChatGPT 프로젝트에 지침과 요청문을 넣어 디자인 초안을 받고, 결과 링크를 시트에 기록할 수 있다.

평가 방법

점수 대신 결과물이 있는지 확인합니다. 수업 마지막 5분 동안 수강생이 직접 체크하고, 강사는 돌아다니며 3번까지 완료했는지 봅니다. 추론·제안

수강생 준비물

  • 노트북과 Chrome 브라우저
  • Google 계정 (시트 사본, Apps Script, AI Studio에 사용)
  • ChatGPT 계정 (프로젝트 기능) 확인 필요 요금제마다 프로젝트·앱 연결 범위가 다를 수 있음
  • Canva 계정 (무료 계정 가능 여부는 수업 전 확인) 확인 필요

강사 사전 준비

  • 원본 시트 공유를 링크가 있는 모든 사용자 · 뷰어로 설정 자료 근거 시작하기 탭 A6
  • 원본에 Apps Script 코드가 설치되어 있고 카드뉴스 AI 메뉴가 뜨는지 확인
  • 사본을 하나 만들어 API 키 등록부터 생성까지 직접 한 번 실행
  • ChatGPT에서 Google Drive·Canva 연결이 수강생 계정에서 되는지 확인 확인 필요
  • 연결이 안 될 때 쓸 백업: 시트를 .xlsx로 내려받아 업로드하는 방법

오늘의 전체 흐름

시트가 작업대 역할을 합니다. 모든 단계의 결과가 시트 한 줄에 모입니다.

  1. Google Sheets기획 입력타깃·주제·장수를 한 줄에 적는다 (B~I열)
  2. Gemini API원고 자동 생성표지 훅, 1~6장 원고, 이미지 프롬프트가 채워진다 (J~Q열)
  3. 사람검토와 수정사실, 과장, 길이를 직접 확인하고 고친다
  4. ChatGPT 프로젝트기획 보강·디자인X열 요청문으로 게시 문구와 이미지 구성, Canva 디자인을 받는다
  5. Google Sheets기록·관리Z열에 결과 링크, E열 상태 변경, 게시 후 성과 입력

자료 근거시작하기 탭 A10, 카드뉴스 관리 탭 A3. 시트의 제작 상태는 아이디어 → 구성안 → 이미지생성 → 디자인 → 검토 → 완료 6단계입니다.

실습 2. Gemini로 원고 자동 생성

학습자용 내용

내 시트에는 이미 카드뉴스 AI라는 메뉴가 들어 있습니다. 이 메뉴가 Gemini에게 "이 타깃, 이 주제로 6장 원고를 써 줘"라고 대신 요청하고, 받은 답을 시트 J~Q열에 적어 줍니다. 이때 내 계정임을 알려 주는 열쇠가 API 키입니다.

API 키는 비밀번호처럼 다룹니다. 채팅방, 시트 셀, 단체 메신저에 붙여 넣지 않습니다. 등록 메뉴에 넣은 키는 시트 셀이 아니라 내 계정의 비공개 저장 공간에 보관됩니다. 자료 근거A12 코드 setGeminiApiKey 안내 문구
활동 안내 · 단계 A. API 키 발급
  1. Google AI Studio API 키 페이지에 내 Google 계정으로 들어갑니다.
  2. 약관 동의 창이 나오면 읽고 동의합니다.
  3. API 키 만들기를 누르고, 만들어진 키를 복사해 둡니다.

일반 지식버튼 이름과 화면 구성은 바뀔 수 있습니다. 확인 필요무료 사용 한도와 데이터 활용 조건은 Gemini API 가격 안내에서 수업 직전에 다시 확인합니다.

활동 안내 · 단계 B. 키 등록과 권한 승인
  1. 내 시트로 돌아와 새로고침(F5)합니다. 상단에 카드뉴스 AI 메뉴가 생길 때까지 10초쯤 기다립니다.
  2. 카드뉴스 AI → 1. Gemini API 키 등록을 누릅니다.
  3. 처음이면 승인 필요 창이 뜹니다. 계속 → 내 계정 선택 → "확인되지 않은 앱" 화면에서 고급 → (프로젝트 이름)(으)로 이동 → 권한 항목 모두 선택 → 허용
  4. 다시 1. Gemini API 키 등록을 눌러 복사한 키를 붙여 넣고 확인을 누릅니다. "API 키가 등록되었습니다." 알림이 뜨면 끝입니다.

일반 지식내가 만든 스크립트는 Google 심사를 받지 않아 "확인되지 않은 앱" 경고가 나옵니다. 강사가 배포한 템플릿처럼 출처를 아는 코드일 때만 허용합니다.

활동 안내 · 단계 C. 자동 생성
  1. 카드뉴스 관리 탭에서 내가 입력한 행의 A열 체크박스를 체크합니다.
  2. 카드뉴스 AI → 2. 체크된 행 자동 생성을 누릅니다. 오른쪽 아래에 "체크한 항목 1/1 생성 중" 알림이 뜹니다.
  3. "완료: 1개" 창이 뜨면 J~Q열을 확인합니다. 성공한 행은 체크가 자동으로 풀립니다.
  4. 실패하면 체크가 남아 있습니다. 오류 문구를 읽고 오류 해결 표를 확인한 뒤 다시 실행합니다.

실습 3. ChatGPT 프로젝트로 기획 보강과 디자인

학습자용 내용

ChatGPT 프로젝트는 지침과 참고 자료를 한 번 넣어 두면 그 안의 모든 대화에 적용되는 작업 공간입니다. 카드뉴스를 만들 때마다 긴 설명을 반복하지 않고, 시트의 요청문만 붙여 넣으면 됩니다. 자료 근거GPT 프로젝트 설정 탭 A3

활동 안내
  1. ChatGPT 왼쪽 사이드바에서 새 프로젝트를 만들고 이름을 키보드 카드뉴스 제작실로 정합니다.
  2. 프로젝트 오른쪽 위 ⋯ → 프로젝트 설정에서 프로젝트 지침을 그대로 붙여 넣고 저장합니다.
  3. 프로젝트 소스에 내 사본 시트를 연결합니다. Google Drive 연결이 안 되면 파일 → 다운로드 → Microsoft Excel(.xlsx)로 받아 업로드합니다. 디자인 참고용 카드뉴스 이미지(JPG·PNG)가 있으면 함께 올립니다.
  4. 요청문 주소 고치기 (중요) 내 시트의 X열 요청문에는 원본 시트 주소가 들어 있습니다. 요청문을 복사한 뒤 첫 줄의 주소를 내 사본 주소로 바꿔서 붙여 넣습니다. (내 주소는 브라우저 주소창에서 복사)
  5. 프로젝트 안에서 새 채팅을 열고 고친 요청문을 붙여 넣어 실행합니다.
  6. 결과를 순서대로 확인합니다: ① 전체 기획 요약 ② 장별 원고 표 ③ 이미지 구성 ④ 대표 이미지 프롬프트 ⑤ 인스타그램 게시 문구

일반 지식OpenAI 도움말 기준으로 프로젝트 지침은 프로젝트 설정에서 넣고, 해당 프로젝트 안에서만 적용됩니다. Google Drive 파일은 링크를 소스로 추가할 수 있지만, 프로젝트 안에서는 자동 동기화가 되지 않습니다. 시트를 고친 뒤에는 다시 확인하도록 요청하세요. 확인 필요요청문의 @Google Drive, @Canva 호출 방식은 도움말에서 확인하지 못했습니다. 안 되면 입력창의 + 도구 메뉴에서 앱을 선택합니다.

강사 노트

수업 전 꼭 확인할 것

  • 확인 필요모델 gemini-3.5-flash-lite를 무료 키로 호출할 수 있는지, 하루 한도는 얼마인지 공식 가격·한도 페이지에서 확인. 검색한 자료 중 Google 공식 문서는 없었음.
  • 확인 필요코드의 thinkingConfig.thinkingLevel: 'minimal' 설정을 이 모델이 받는지. 오류가 나면 이 설정을 지우면 됨.
  • 확인 필요수강생 ChatGPT 요금제에서 프로젝트, Google Drive 연결, Canva 앱을 쓸 수 있는지.
  • 확인 필요AI Studio 키 발급은 계정 연령·지역 조건이 있을 수 있음. 키를 만들 수 없는 수강생을 위해 강사 시연 화면으로 대체할 계획을 세워 둠.
  • 강사 사본으로 처음부터 끝까지 한 번 실행하고 걸린 시간을 기록.

배포 전 시트 정리 권장

  • X열 요청문: 원본 주소가 수식에 고정됨 → 사본에서도 원본을 가리킴. 실습 3 강사 설명 참고.
  • 대시보드 지표: "저장률 = 저장수 ÷ 조회수"로 정의되어 있으나 관리 탭에 조회수·저장수 열이 없음. 열을 추가하거나 정의 문구를 클릭수·전환수 기준으로 수정.
  • 예시 데이터: KB-009~011이 같은 주제로 중복, KB-012 "리리니어" 오타, KB-006·008 결과물 링크가 기본 주소뿐. 성찰 활동 예시로 쓰려면 오타는 남겨 두는 것도 방법.
  • 장수 불일치: GPT 지침은 장수 조절 허용, Gemini 자동화는 6장 고정.
  • 분야 고정: buildPrompt_ 첫 줄이 "키보드 분야 … 편집자"로 고정. 2회차에 수강생 분야로 바꾸려면 이 줄과 GPT 지침을 함께 수정.

가정한 내용

  • 가정수강생은 Google 계정과 ChatGPT 계정이 있고, 시트 기본 조작(셀 입력, 탭 이동)을 할 수 있음.
  • 가정1회차 실습 주제는 템플릿과 같은 키보드 분야로 진행. 내 분야 적용은 2회차.
  • 가정수강생 1인 1노트북, 강사 화면 공유 가능.
  • 추론·제안시간이 부족하면 실습 3에서 Canva 제작을 빼고 ①~⑤ 텍스트 결과까지만 진행. 디자인은 과제로 돌림.
