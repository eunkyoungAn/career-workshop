# 내일의 나 · 커리어 워크숍

남부여성발전센터 M365 시스템 운영 관리자 과정의 자기이해·취업 준비 활동을 위한 모바일 웹사이트입니다. 빌드 없이 GitHub Pages에서 동작합니다.

## 수업 진행 방법

1. 사이트의 **강사 공간**에서 별도로 전달받은 **4자리 강사번호**를 입력합니다. 수업 이름을 적고 **수업방 열기**를 누릅니다.
2. **참여 링크·QR**을 교육생에게 나눠 줍니다. 교육생은 링크를 열고 **닉네임**을 정해 참여합니다. 실명이나 계정은 요구하지 않습니다.
3. 교육생은 커리어 자산 → 강점 발견 → 코칭 휠 → 취업 계획서 순서로 작성합니다.
4. 각 활동 아래의 **이 활동 익명으로 공유**를 누른 응답만 강사 화면에 모입니다. 고친 뒤 다시 공유하거나 공유를 취소할 수 있습니다.
5. 강사는 **발표 화면 열기**로 별도 창을 엽니다. 그 창에서도 강사번호를 입력한 다음 프로젝터에 보여줍니다. 활동별·익명 참여자별로 볼 수 있으며, **발표에서 숨기기**를 누른 내용은 발표 창에 나타나지 않습니다.
6. 교육생은 **계획서 이미지 저장**으로 개인 결과를 보관합니다. 휴대폰에서는 이미지 다운로드, 이미지 길게 누르기, 지원 기기의 공유 기능을 사용할 수 있습니다.

**수업 중 강사 화면을 계속 열어 두세요.** 강사와 교육생 기기가 인터넷에 연결되어 있어야 실시간 공유할 수 있습니다. 강사 기기의 절전 모드를 잠시 해제하고 모바일 교육생은 화면을 다시 켠 뒤 필요하면 **다시 연결**을 눌러 주세요. 기관 네트워크에서 WebRTC가 차단되면 공유 연결이 되지 않을 수 있으며, 개인 작성과 이미지 저장은 계속 사용할 수 있습니다.

## 활동 구성

- **커리어 자산:** 흥미·가치·경험·역량·현실조건. 항목마다 예시 문장 2개를 항상 표시합니다. DISC 앞에서 경험을 먼저 떠올리도록 배치했습니다.
- **강점 발견:** 기존 DISC 결과는 선택적으로 참고합니다. 새로운 검사를 시행하거나 유형으로 능력을 판정하지 않습니다. 실제 경험 5문항과 강점 문장을 작성합니다.
- **코칭 휠:** 원본의 8개 영역을 유지합니다. 1~10점과 이유를 기록하고, 점을 누르거나 키보드로 선택하면 해당 이유가 표시됩니다. 현재는 파랑 점선, 목표는 주황, 실제 실행 후는 초록입니다. 선택하지 않은 목표나 아직 측정하지 않은 실행 후 점수는 만들어 넣지 않습니다.
- **취업 계획서:** 한 줄 소개, 희망 직무, 취업 희망 시기, 지금 할 일 3가지, 미래의 나에게 할 말을 PNG로 저장합니다. 이메일·AI API는 사용하지 않습니다.

## 저장과 익명 공유

- 개인 초안은 해당 **브라우저의 로컬 저장 공간**에만 자동 저장됩니다. 같은 링크·같은 브라우저로 돌아오면 이어 쓸 수 있습니다. 수업방별 초안과 개인 활동 초안은 구분됩니다.
- 닉네임은 수업방마다 이 기기에 저장됩니다. 다음 접속에는 같은 닉네임으로 이어서 참여하며, 활동 화면의 **닉네임 변경**에서 바꿀 수 있습니다. 강사와 연결되면 이전에 공유한 응답에도 새 닉네임이 반영됩니다. 동일한 닉네임을 쓰더라도 브라우저별 참여자 식별자로 응답을 구분하며 서로의 답을 덮어쓰지 않습니다.
- 공유한 응답은 암호화된 WebRTC 데이터 채널로 강사에게 전달되어 **강사 브라우저**에 저장됩니다. 성공 표시 전에 강사 쪽 저장 확인을 받습니다.
- GitHub에는 프로그램 소스만 저장됩니다. 교육생 응답을 GitHub에 올리지 않습니다.
- 실명·이메일·연락처를 요구하지 않습니다. 교육생이 직접 정한 닉네임으로 강사 화면과 발표 화면에 표시하고, 구분을 위한 짧은 참여자 식별자를 함께 보여줍니다. 닉네임이나 응답에 실명·연락처를 적으면 익명이 유지되지 않으므로 입력 안내를 제공합니다.
- 브라우저 데이터를 삭제하거나 다른 기기로 바꾸면 기존 초안·강사 수업방을 복원할 수 없습니다. 중요한 개인 결과는 이미지로 저장해 주세요.
- 강사 공간과 발표 화면은 4자리 강사번호로 잠금을 해제합니다. 새 창이나 새로고침 후에는 다시 입력합니다. **강사 공간 잠금**을 누르면 같은 브라우저의 발표 화면도 잠깁니다. 수업방은 **그 수업방을 만든 브라우저**에서 관리하며, 강사번호를 알아도 다른 기기의 저장된 응답을 불러올 수는 없습니다.
- 강사번호 원문은 소스에 저장하지 않습니다. PBKDF2-SHA256(600,000회)와 AES-GCM으로 강사 서명 키 및 로컬 수업방을 보호하고, 참여자는 수업방 인증 서명을 확인한 뒤 응답을 전달합니다. 기존 수업방은 처음 강사번호를 입력할 때 암호화 저장으로 전환됩니다. 기존 참여 링크는 유지됩니다.
- 사용자가 요청한 **4자리 번호는 간편 출입 잠금**입니다. 10,000가지 조합의 짧은 번호이므로 공개된 암호문에 대한 오프라인 추측을 막는 고강도 계정 인증을 대신하지 않습니다. 계정별 권한·번호 회수·서버 측 시도 제한이 필요하면 별도 인증 서버를 사용해야 합니다. 공유 PC에서는 수업 후 수업방과 응답을 삭제하세요.
- 참여 링크에는 강사 공개키만 담습니다. 연결 시 ECDSA 서명으로 강사와 브라우저 참여자 소유권을 검증합니다. 강사 비밀키는 로컬에 남습니다.
- PeerJS의 공개 연결 중개 서버를 사용합니다. 이 서버는 연결 메타데이터를 다루며 응답 본문은 애플리케이션 저장소로 수집하지 않습니다. 별도 운영 서버가 없는 방식이므로 강사 탭을 닫으면 공유를 받을 수 없습니다. 자동 클라우드 백업은 없습니다.

## 개발 및 배포

Node.js 22 이상에서:

```sh
npm test
npm start
```

미리보기 주소: `http://127.0.0.1:4173`

GitHub Pages 설정에서 `main` 브랜치의 `/ (root)`를 배포 소스로 지정합니다. `.nojekyll`이 포함되어 있으며 외부 빌드 작업은 필요 없습니다. HTTPS 또는 localhost에서 실행해야 WebCrypto와 파일 공유 기능을 사용할 수 있습니다.

## 포함된 라이브러리

- PeerJS 1.5.5 (MIT) — `vendor/peerjs.min.js`
- qrcode-generator 2.0.4 (MIT) — `vendor/qrcode.js`

외부 글꼴, 분석 추적, 광고, 카메라·마이크 권한 요청은 없습니다.

공식 참고: [PeerJS 문서](https://peerjs.com/docs/), [GitHub Pages 배포 안내](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)
